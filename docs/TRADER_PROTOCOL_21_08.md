## Три вопроса по порядку

Q1 куда перевес: дельта = Σ B - Σ S, нормировать на оборот выборки, <15% шум — читать не стоит

Q2 двигает ли поток цену — ключевой: сколько рублей цены агрессор получил на объём. Влил и сдвинул → контролирует, влил и вернулось → поглотили. Правило асимметрии: сравнивать не размер, а результат. buy_move vs sell_move, buy_eff vs sell_eff. Поглощение важнее направления: ASTR 19.08 07:45 продали 182186 лотов vs 2008 покупок без сдвига цены, кумулятивная дельта max +738270 ровно на максимуме дня 211.8

### Действующий порядок у терминала (с правками 21.08)

1. 10:50 — снять оборот первого часа 09:50–10:49 по IMOEX2. Ниже ~7.5 млрд ₽ = сжатый, работаем. Выше = молчим весь день. Утренний оборот не смотреть.
2. С 10:40 (первое арифметически возможное срабатывание) до 16:00 — следить за 10-минутными бакетами IMOEX2: value ≥3× среднего пяти предыдущих бакетов основной сессии. База не должна захватывать утреннюю сессию.
3. Направление — знак close−open бакета-триггера. Вход по его закрытию. Всплеск после 16:00 не торговать.
4. Инструмент — нормированная эффективность (% хода цены на 1% дневного объёма в чистой дельте) в сторону сигнала, только из бумаг с дельтой того же знака. Эффективность — сортировщик, не предиктор.
5. Подтверждение — взрыв trade_count по бумаге, не величина дельты. Стоп за экстремум кумулятивной дельты.
6. R/R≥2 арифметически, иначе входа нет. На такой статистике это единственное, что удерживает серию от отрицательного мат. ожидания.
7. Размер — минимальный. Журнал обязателен: режим, кратность, время, инструмент, результат в R.

### Технические находки (дополнение к разделу «Сбор данных»)

- Веб-загрузчик отдаёт ISS только при fast_mode:false. При fast_mode:true возвращается "Unable to load" / "Content not available". Воспроизведено на candles.json и на marketdata.
