## Порядок получения дельты (обязателен)

1. NUMTRADES из marketdata: `securities.json?iss.only=marketdata&securities=TICKER`
2. `start = NUMTRADES-100`
3. `trades.json?start=START&limit=100&iss.only=trades&fast_mode=false`
   - `fast_mode:true → Content not available`
   - `reverse=true` игнорируется
   - `limit` только 100 (limit=30 молча 10)
   - TRADINGSESSION 0 утро 1 основная 2 вечер vs flow session morning/main
   - Лаг 15-19 мин (замер 21.08: последний принт 14:55:53 при времени 15:19)
   - ISS кэш ~10 мин, MOODEX ~5 мин

Плотность:
- 100 сделок MGNT 21.08 = 11 мин → запрос каждые 10 мин даёт непрерывную дельту
- >3 млрд/день (SBER 70875 к 14:56) 100 сделок <1 мин — точечная проверка

## Три вопроса по порядку

### Q1: куда перевес
- дельта = Σ B - Σ S
- нормировать на оборот выборки: imbalance_pct = |delta|/total *100
- <15% шум — читать не стоит

### Q2: двигает ли поток цену — ключевой
- Сколько рублей цены агрессор получил на свой объём
- Влил и сдвинул → контролирует, влил и вернулось → поглотили
- Правило асимметрии: сравнивать не размер, а результат
  - buy_move vs sell_move, buy_eff_per_pct_vol vs sell_eff_per_pct_vol
  - Если продажи двигают -4₽, а покупки +1₽ и отдают за 90 сек → контроль продавца
- Поглощение важнее направления: ASTR 19.08 07:45 продали 182186 лотов vs 2008 покупок без сдвига цены, кумулятивная дельта max +738270 ровно на максимуме дня 211.8

### Q3: по каким ценам идут принты
- Продажи по нисходящим = пробивает уровни
- Клипы одного размера (64/64/64/30/30/30) = алгоритм айсберг
- Один гигантский без продолжения = разовая ликвидация
- Уровень работы агрессора: MGNT продавец ровно 1613 три принта — пока не отбит вверх, инициатива его

## Стоп и отмена — только по исполненным сделкам

Стоп за провалившийся экстремум агрессора, которого поглотили.
MGNT покупатель не удержал 1617 → стоп шорта 1619 (возврат выше = пришёл с деньгами, которых не хватило).

Отмена формулируется в сделках, не в заявках:
- Пачка агрессивных покупок >500 акций, после которой минута закрывается выше 1617 (успешный повтор провалившейся попытки)
- Продажи 300+ перестают опускать цену — исчезла асимметрия (Q2)

R/R≥2 с комиссией 0.05% в обе стороны (при тесном стопе до 15% риска)

## Правила

- Исчерпания: крупнейший принт в конце выборки чаще завершение программы
- Дивергенция внутри дня: новый экстремум дельты без нового экстремума цены → входа нет (работает внутри дня, 11/13 для экстремума дня)
- Проверка одним критерием: сделал ли агрессор новый экстремум цены
- Лаг 15-19 мин дефект для входа — годится для выхода/стопа
- Дискреционный вход без индексного триггера 3× — вне триггера 1/1 убыток vs с триггером 4+/2-/1 ноль на 14д
- Пробойные лонги убыточны 181д лучшая -0.113R после издержек — формулировка «структура и план»
