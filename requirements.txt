#
# ВНИМАНИЕ ПРО torch. Строка --extra-index-url ниже НЕ гарантирует CPU-сборку:
# extra-index не задаёт приоритет источника, pip сливает оба индекса и выбирает
# по версии. Пин 2.4.1 без суффикса одинаково подходит и к 2.4.1 с PyPI
# (797 МБ + 12 пакетов nvidia-*, свыше 3 ГБ), и к 2.4.1+cpu (195 МБ).
#
# В Docker это решено жёстко: Dockerfile ставит torch ОТДЕЛЬНЫМ шагом с
# --index-url на индекс PyTorch, до обработки этого файла, и роняет сборку,
# если в образе появились пакеты nvidia-*. Строки ниже оставлены для локальной
# установки, в том числе на macOS, где колёс +cpu нет вовсе.
# Меняешь версию torch — меняй И в Dockerfile.
--extra-index-url https://download.pytorch.org/whl/cpu
